DSH Mobile UI 1.1.2 uses GitHub Actions and npm Trusted Publishing for automated releases with provenance. Mobile UI behavior is unchanged from 1.1.1.

Install or update:

```sh
dsh plugin --profile web add @canary-builds/dsh-mobile-ui
```

Restart DSH and refresh your browser after updating. This is a plugin for your existing DSH web UI, with enhancements scoped to mobile and standalone app windows.

The GitHub release includes the prebuilt package and SHA256SUMS.
